# Acumatica Extension Control Center

This repository is designed to hold remote configuration for the Acumatica Firefox extension.

## Folders

- `config/` — JSON configuration consumed by the extension.
- `dashboard/` — static dashboard starter.

## Important

Do not store passwords, GitHub Personal Access Tokens, customer data, or other secrets in these JSON files.

The current dashboard is a configuration editor prototype. GitHub API write-back/authentication is intentionally not included until the repository is created and its exact owner/repository name is known.
